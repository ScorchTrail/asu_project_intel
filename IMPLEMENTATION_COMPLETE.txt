## Gallery Implementation Details

### HTML Structure
```html
<section class="gallery">
  <div class="gallery__container container">
    <h2 class="gallery__heading">Sustainability in Action</h2>
    <div class="gallery__wrapper">
      <div class="gallery__track" id="galleryTrack">
        <!-- 6 gallery cards with image + content -->
      </div>
    </div>
    <div class="gallery__controls">
      <button class="gallery__button gallery__button--prev" id="galleryPrev">
        <i class="bi bi-chevron-left"></i>
      </button>
      <button class="gallery__button gallery__button--next" id="galleryNext">
        <i class="bi bi-chevron-right"></i>
      </button>
    </div>
  </div>
</section>
```

### CSS Classes (BEM)
- `.gallery` - Main section
- `.gallery__container` - Content wrapper
- `.gallery__heading` - Section title
- `.gallery__wrapper` - Overflow container
- `.gallery__track` - Card container (animated)
- `.gallery__card` - Individual card (33.33% width)
- `.gallery__image` - Card image
- `.gallery__content` - Card text content
- `.gallery__card-title` - Card heading
- `.gallery__card-text` - Card description
- `.gallery__controls` - Navigation button container
- `.gallery__button` - Navigation button
- `.gallery__button--prev` / `--next` - Directional modifiers

### JavaScript Behavior
```javascript
- Calculate card width: 280px (card) + 24px (gap) = 304px
- Track position updates with click events
- Transform X-axis based on position
- Button enable/disable based on scroll position
- Smooth animations using CSS transition
```

## Alignment Strategy

### Gallery Cards Alignment with Features Cards
The gallery cards are designed to align seamlessly with the three-column feature cards below:

1. **Container Alignment**
   - Both use Bootstrap `.container` class
   - Same max-width constraint (1200px)
   - Centered on page

2. **Card Width Synchronization**
   - Gallery: 280px base width (33.33% of container)
   - Features: 280px (col-lg-4, 33.33% of container)
   - Matching dimensions ensure visual alignment

3. **Spacing Consistency**
   - Gallery gap: 1.5rem (24px)
   - Features gap: Bootstrap g-4 class (1.5rem)
   - Equal spacing maintains visual rhythm

4. **Responsive Consistency**
   - Both sections use same breakpoints
   - Tablet: Cards adjust together
   - Mobile: Single-column for both
